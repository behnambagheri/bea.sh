مهندس دواپس (DevOps)

۲۰۲۱ - اکنون

کلاسترهای کوبرنتیز on-prem برای میکروسرویس‌های بک‌اند و فرانت‌اند.

  • طراحی، راه‌اندازی و نگهداری کلاسترهای کوبرنتیز on-prem با بیش از ۳۰ نود.
  • ساخت و نگهداری بیش از ۲۰۰ پایپ‌لاین CI/CD با Atlassian Bamboo و Bitbucket.
  • اتوماسیون مدیریت بکاپ، گزارش‌گیری، اعلان‌های دیپلوی و فرایندهای عملیاتی با Bash و Python.
  • اتصال Bamboo، Bitbucket، Jira و Sentry با وب‌هوک برای سیگنال‌های دیپلوی و حوادث.
  • پیاده‌سازی مانیتورینگ و هشدار با Prometheus، Grafana و Alertmanager.
  • مدیریت حوادث production شامل خرابی سخت‌افزار، قطعی دیتابیس و اختلالات شبکه.
  • تدوین پلی‌بوک‌های امنیتی، روال‌های بازیابی، مکانیزم‌های rollback، ران‌بوک‌های بازیابی PostgreSQL و فرایندهای انتشار مرحله‌ای (staged rollout).

راهنمای استفاده از مخزن APT

ابتدا روش سریع راه‌اندازی و سپس تنظیمات دستی را می‌بینید.

پیشنهادی

اسکریپت راه‌اندازی

curl -fsSL https://registry.behnam.pro/bootstrap-apt.sh | sudo bash

تنظیم دستی مخزن بر اساس نسخه اوبونتو:

Ubuntu 24.04 (Noble)

sudo tee /etc/apt/sources.list.d/bea-proxy.list > /dev/null <<'EOF'
deb https://registry.behnam.pro/ubuntu noble main universe restricted multiverse
deb https://registry.behnam.pro/ubuntu noble-updates main universe restricted multiverse
deb https://registry.behnam.pro/ubuntu noble-security main universe restricted multiverse
EOF
